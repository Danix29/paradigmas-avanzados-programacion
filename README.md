## About

**Asignatura:** Paradigmas Avanzados de Programación · UAH GII · Curso 2026-27 · 3er Curso

A tour of programming paradigms beyond object orientation: what each one optimises for, and why picking the right paradigm can make a problem trivial instead of tangled.

---

## Topics covered

| Block | Content |
|-------|---------|
| Functional Programming | Pure functions, higher-order functions, immutability, lazy evaluation, Haskell |
| Type Systems | Static vs dynamic typing, type inference, algebraic data types, generics |
| Logic & Declarative Programming | Prolog revisited from a paradigm-comparison angle, constraint programming |
| Metaprogramming & Reactive Styles | Macros/reflection, reactive and event-driven programming models |
